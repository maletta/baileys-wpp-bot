# ADR-0001: Escolha da Biblioteca Baileys para WhatsApp Integration

## Status

**Accepted** - 2025-01-27

## Contexto

Precisamos de uma solução robusta para integração com WhatsApp que permita:

- Conexão via QR Code como dispositivo secundário
- Escuta de eventos de grupos (entrada/saída de participantes)
- Envio de mensagens em grupos
- Gerenciamento de sessões de forma estável

## Decisão

Utilizaremos a biblioteca **Baileys** na versão 7.0.0-rc.3 como solução principal para integração WhatsApp.

## Alternativas Consideradas

### 1. WhatsApp Business API Oficial

- **Prós**: Suporte oficial, estabilidade garantida
- **Contras**: Custo elevado, limitações de funcionalidades, processo de aprovação complexo
- **Razão da rejeição**: Não atende requisitos de participação em grupos existentes

### 2. Puppeteer + WhatsApp Web

- **Prós**: Controle total da interface
- **Contras**: Muito instável, quebra frequentemente, performance ruim
- **Razão da rejeição**: Manutenção excessiva e instabilidade

### 3. Baileys (Escolhida)

- **Prós**:
  - Open source e ativa comunidade
  - Suporte completo a grupos
  - Multi-device support nativo
  - TypeScript support
  - Event-driven architecture
- **Contras**:
  - Dependente de engenharia reversa do protocolo
  - Possíveis breaking changes do WhatsApp
  - Necessita handling cuidadoso de reconexões

## Consequências

### Positivas

- Funcionalidades completas para gerenciamento de grupos
- Código TypeScript nativo facilita desenvolvimento
- Comunidade ativa para resolução de problemas
- Flexibilidade total para customizações
- Custo zero de licenciamento

### Negativas

- Risco de quebra por mudanças no WhatsApp
- Necessidade de monitoramento constante de atualizações
- Responsabilidade de implementar reconnection logic
- Possível necessidade de proxy/multi-instância para escala

### Riscos Mitigados

- **Atualização automática**: Configurar dependabot para atualizações
- **Monitoring**: Implementar health checks e alertas
- **Backup de sessões**: Armazenamento seguro de credenciais
- **Reconexão**: Implementar retry logic robusto
